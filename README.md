# 📊 Projeto de Análise de Preços Globais de Smartphones - 2025

## 📌 Resumo do Projeto
Este projeto realiza uma **análise exploratória de dados (EDA)** com base em um<br>
conjunto de dados fictício contendo informações sobre smartphones vendidos<br>
globalmente em 2025.<br>
A base utilizada é um arquivo *.csv* disponível no **kaggle**, contendo dados como<br>
marca, modelo, preço, hardware e avaliações dos dispositivos.

## ✅ Objetivo do Projeto
Este projeto foi desenvolvido com o objetvo de praticar **análise de dados**, **manipulação<br>
de DataFrames**, **Análises Exploratórias** e **criação de visualizações** para responder<br>
perguntas de negócios.<br>
 

## 🗂️ Sobre o Conjunto de Dados
O dataset contém **1000** registros e **15** colunas, incluindo:
- Marca de aparelho
- Modelo de celular
- Preço em dólar
- RAM (GB)
- Armazenamento (GB)
- Câmerea (MP)
- Bateria (mAh)
- Tamanho da tela (polegadas)
- Potência de carregamento (W)
- Suporte a 5G
- Sistema operacional
- Processador
- Avaliação dos usuários
- Mês de lançamento
- Ano


## 🛠️ Tecnologias Utilizadas
- **Python 3.11.9**
- **Pandas** - manipulação de daods
- **Matplolib** - visualização de dados


## 📌 Principais Análises Realizadas
Este projeto responde a várias perguntas de negócios, como:
- Quais marcas aparecem com mais frequência ?
- Quais são os modelos e marcas mais bem avaliados?
- Quais são os modelos e marcas menos avaliados?
- Quantas avaliaçõesnegativas cada modelo recebeu?
- Qual sistema operacional é o mais utilizado?
- Qual foi o faturamento total por mês?
-  Quantos celulares foram lançados por mês?
-  Como o suporte ao **5G** impacta preço e avaliação?


## 📈 Visualizações Gráficas
Foram criados gráficos como:
- Gráficos de barras com a quantidade de aparelhos por marca
- Gráfico de pizza com distribuição dos sistemas operacionais
- Gráfico de linha com faturamento mensal
- Gráfico de lançamento por mês
